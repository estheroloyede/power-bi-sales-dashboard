# Power BI Sales Dashboard

## Project Overview

This project is an interactive Power BI dashboard created to analyze sales performance and generate meaningful business insights.

The dashboard provides a clear overview of sales, profit, customers, products, regions, and monthly performance.

## Tools Used

* Power BI
* Power Query
* DAX
* Data Cleaning
* Data Visualization

## Key KPIs

* Total Revenue
* Total Cost of Goods Sold (COGS)
* Total Profit
* Customer Count
* Monthly Customer Performance

## Dashboard Analysis

The dashboard analyzes:

* Sales performance by product
* Sales performance by region
* Monthly sales trends
* Customer performance
* Profit and revenue
* Product performance

## Key Insights

The dashboard helps identify the best-performing products and regions, track monthly trends, and understand customer and sales performance.

## Project Goal

The goal of this project was to develop my practical skills in data analysis, data visualization, KPI development, and creating interactive business dashboards using Power BI.
